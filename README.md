# 🏗️ Low Level Design (LLD)

A personal repository for practicing **Low Level System Design and Object-Oriented Design principles** through real-world interview problems.

This repository focuses on building strong system thinking and clean software design skills.

---

## 🎯 Purpose

- Improve object-oriented design skills
- Practice designing real-world systems
- Strengthen understanding of SOLID principles
- Prepare for LLD rounds in interviews

---

## 🧠 Design Approach

Each system is designed using the following steps:

1. Understand requirements clearly
2. Identify core entities
3. Define relationships between entities
4. Design classes with responsibilities
5. Apply OOP principles (Encapsulation, Inheritance, Polymorphism, Abstraction)
6. Use design patterns where necessary
7. Consider edge cases and extensibility

---

## 📌 Core Concepts Used

- Object-Oriented Programming (OOP)
- SOLID Principles
- Design Patterns:
  - Strategy Pattern
  - Factory Pattern
  - Singleton Pattern
  - Observer Pattern
